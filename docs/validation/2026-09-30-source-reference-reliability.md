## Method and limits

Start with synthetic regressions for each observed mechanical defect, exercise the
actual initial/repair/validation paths, then independently check literal passages in
the four existing public primary PDFs. Verify the browser with synthetic provider-free
inputs and inspect saved accepted JSON, screenshots and Word packages. Revalidate
historical accepted Guinea only in memory, without changing or rerunning that assessment.
Rejected provider output is neither inspected nor stored. Failure diagnostics contain
allowlisted reason/count aggregates, not quotations, identifiers or rejected values.

Literal grounding verifies wording and its supplied source location. It does not verify
relevance to a driver, institutional ownership within a passage, analytical conclusions,
present-day event dates, recommendation feasibility or source completeness. The percentage
guard checks values in cited primary/package text, not their meaning; other numerical forms
and semantic entailment are not automatically verified.

## Changes

- A shared standard-library matcher uses only each record's cited primary/package
  document facts. It copies real coordinates and the literal source span when the match
  is unambiguous. Repeated passages at different locations remain unresolved unless the
  original stated coordinate is itself valid. Empty, partial-word and unsupported
  paraphrased excerpts cannot bypass validation.
- Locator repair retains original priority links and admits an additional existing source
  ID only when that source grounds the corrected target. Synthetic tests exposed and fixed
  the previous loss of a repaired target's source ID. This is not an established explanation
  of the historical Afghanistan failure; its rejected locators were not inspected.
- Each RRA `cpf_response` is now a verified quotation from its own cited CPF/package
  evidence. Browser and detailed Word views display the source location and separate
  delivery/results analytical fields. A fixed no-quotation disclosure is allowed only for
  `not_evidenced` or `not_assessable` rows. An independent review identified and closed a
  bypass where uploaded text containing that disclosure could otherwise authorize an
  aligned row. Valid responses, row identities, standing and unrelated analysis survive
  bounded repair; invalid responses remain blocking.
- Unsupported percentage recommendations are fatal. Review/repair prompts v3.0.8 separate
  government actions from CPF commitments, preserve each event's own date and require source
  quotations. Prompt instructions do not establish factual acceptance. Repair receives
  existing source text/roles inside the unchanged 160,000 estimated-input-token gate.

The public result field layout, four-per-UTC-day admission cap, client/queue/assistant/stream
limits, model output limits and bounded model-call behavior remain unchanged. No dependency
or new provider call was added. Existing accepted historical outputs were not rewritten.
