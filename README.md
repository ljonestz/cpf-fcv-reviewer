# CPF FCV Reviewer

CPF FCV Reviewer is an advisory service for structured review of Country Partnership Framework packages through an FCV lens. It supports expert judgment; it does not make policy determinations.

## Data and deployment boundaries

- The Render deployment accepts only approved historical, synthetic, or otherwise non-sensitive document packages.
- Review state is stored only in volatile memory and is not retained durably.
- The service must not be used to establish or represent official policy conclusions.
- This repository and service are separate from the stable FCV Project Screener; changes here must not affect that system.
